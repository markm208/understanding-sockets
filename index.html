Sockets in Java

Java has a wonderfully simple API for working with sockets. Even though we have been focusing on C/C++ development, I want to start by showing how to use the Socket API in Java.

The first playback gives you a very brief overview of Java from the perspective of a C/C++ programmer. If you have experience programming with Java you can skip the first playback.

The second playback shows the basics of socket programming in Java. Pay attention to what is being created and what the different parts of the code are doing. It is a bit messier in C so you'll see a simple implementation in Java first.

The third playback walks you through creating a simple chat application using Java sockets. The important part about this playback is thinking about the protocol design and the Socket programming concepts.

  1. Hello World in Java
  2. Sockets in Java
  3. Designing an Instant Messenger Protocol with Java Sockets

Sockets in C

This chapter focuses exclusively on socket programming in C. You'll learn the fundamentals of creating and using sockets in the C programming language.

The first playback shows the basics of socket programming in C. It is a bit more complex than the Java examples, but it will give you a solid foundation in C socket programming.

The second playback demonstrates how to create Java-style socket classes in C++. This approach encapsulates socket functionality within classes, making it easier to manage and use sockets in a more object-oriented manner.

The third playback walks you through designing a simple instant messenger protocol using C++ sockets. This playback emphasizes protocol design and the practical application of socket programming concepts in a real-world scenario.

  1. Sockets in C: TCP and UDP Echo
  2. Java-Style Socket Classes in C++
  3. Designing an Instant Messenger Protocol with C++ Sockets
